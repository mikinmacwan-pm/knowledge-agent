# Benefits Eligibility Overview

## §2.2 Emergency assistance income thresholds

| Program | HH size 3 limit | Notes |
| --- | --- | --- |
| Emergency food box | $2,800/mo gross | Verify docs |
| Utility assistance | $2,400/mo gross | See §5.1 — **may conflict with housing programs** |
| TANF | State table link | Benefits counselor required |

## §3.1 TANF — Documents required

- Photo ID for applicant
- Social Security cards (all household members)
- Proof of income (30 days)
- Proof of residency

## §4.1 Medicaid renewal

Disability recipients: renewal window typically 60 days before expiration. Refer to benefits counselor for case-specific dates.

## §5.1 Utility assistance — Community Bridge program

Income limit: **$2,200/mo** for household of 3 (rev 2025-08). **Note:** May conflict with RD-001 Horizon thresholds — escalate if conflict detected.

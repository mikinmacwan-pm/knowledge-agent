# Source Freshness SOP

## §2.1 Review cadence

| Tier | Max age | Action if stale |
| --- | --- | --- |
| A — Crisis/pathway | 6 months | Flag + steward ticket |
| B — Directory | 12 months | Warn in UI |
| C — Training | 18 months | Index deprioritized |

## §3.1 Agent behavior

When source past review date, UI displays stale warning. Agent must not suppress freshness metadata.

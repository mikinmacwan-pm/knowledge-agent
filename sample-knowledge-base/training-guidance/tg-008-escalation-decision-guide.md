# Escalation Decision Guide

## When to escalate (checklist)

- [ ] Confidence below 0.55
- [ ] Two sources conflict
- [ ] Question is clinical, legal, or safety-planning
- [ ] No approved source matched
- [ ] You would not stake your judgment on the summary alone

## How to escalate

Use Escalate button → select reason → add notes → submit. Ticket ID confirms delivery.

# Example Call Workflow Guide

## Sample workflow: housing inquiry

1. **Listen** — capture age, region, urgency (mental notes; no PII in agent)
2. **Query** — "Transitional housing 19-year-old Region B couch surfing"
3. **Review** — read summary + confidence; open citations
4. **Verify** — check bed availability via Housing Line if crisis
5. **Communicate** — share approved info; you decide wording
6. **Document** — log in case system per Documentation SOP
7. **Feedback** — thumbs up/down after call

## Time target

Agent-assisted lookup: ~1–2 min vs ~6–7 min manual search (baseline study target).
